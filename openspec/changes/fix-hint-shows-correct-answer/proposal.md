## Why

Кнопка "Подсказка (сбросить серию)" сбрасывает прогресс, но не показывает правильный ответ. Пользователь вынужден угадывать снова или искать информацию в других источниках, что ухудшает UX обучения.

## What Changes

- Endpoint подсказки будет возвращать `correct_answer` вместе со сбросом серии
- Frontend отобразит правильный ответ при использовании подсказки
- Серия правильных ответов сбрасывается (сохраняется текущее поведение)

## Capabilities

### New Capabilities
- `hint-feedback`: Возврат правильного ответа при запросе подсказки

### Modified Capabilities
- `learning-attempt`: Добавление поля `correct_answer` в ответ endpoint подсказки

## Impact

- `backend/app/api/learning.py` — модификация endpoint подсказки
- `frontend/src/components/ExerciseView.tsx` — отображение правильного ответа
- API контракт: добавление поля в ответ подсказки
